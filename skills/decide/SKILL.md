name: decide
description: Use a locally prepared Scout decision to handle one task, with explicit abstention.
---
For routine work, call scout_handle(task, text) once. The operator should already have calibrated, chosen and trained the local method using the CLI, which uses zero agent tokens. Handle restores its recorded task/dataset/decision after restart and rechecks consent and freshness. An abstention means do the task yourself. There is no automatic cloud fallback. Local masking of a tool argument does not undo the agent's earlier exposure to that argument. Detector coverage is incomplete.

If setup is missing, ask the operator to prepare approved data with CLI configure, calibrate, inspect, choose and train. The operator reviews all relevant facts and recipe requirements; Search must pass the unchanged validation gate and Fields/regex needs no training. The CLI also exposes handle, freeze and one-use evaluate. Do not use the final holdout for selection. Do not turn a quality refusal into a lower error gate.

Only if the user explicitly requests agent-assisted setup, make one Scout call at a time; Hermes rejects batches. Read scout_inspect and full scout_recipes for each candidate. Compare goals, counts, labels, rules and availability with requires. Do not assume the first card is best. The agent chooses; code provides no method recommendation. For scout_choose, give a reason up to 400 characters, without PII, content, paths or secrets; include explicit premises such as label_count>=2 or modality=text. The audit checks stated facts, not all reasoning. Unknown premises are unverified; premise_false contradicts the profile. Respect the audit and task compatibility.

scout_choose records a decision only. For an executable trained method call scout_train separately and review its validation result. Plans cannot execute. scout_predict remains an evaluation path for approved query IDs; do not guess IDs or inspect the holdout to obtain them. Use scout_handle for new work after calibration and setup. Calibration errors are a nearest-prior-label proxy on at most 500 sampled decision rows, not recipe accuracy or real handled tasks. n_total and sampled disclose the sample; all decision rows contribute to the calibration digest.

Local artifacts contain a feature vocabulary from approved training text; Search artifacts also contain document IDs/titles. Recipe shorthand “never terms” refers to public feature summaries and Insights export, not local artifact storage. Do not share profile/artifact files. Aggregate Insights export excludes this vocabulary and identifiers.

Insights distinguishes real handles, refusals, estimated avoided tokens and observed agent usage. Net subtracts observed whole-session agent tokens in sessions using Scout; this is conservative attribution with incomplete-hook risk, not exact tool-only cost or measured bill savings. Without session IDs, the reported accounting scope is the profile process. Usage requires observe consent for the request scope and background/report mode. Without usage, agent setup cost is not measured. Never claim a reduction from calibration replay or invent a setup cost. With mask consent, request middleware masks detected user prompt PII before sending; a category-only notice may report the last user prompt's detected PII under observe consent in report mode.
